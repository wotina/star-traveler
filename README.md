# 小小旅行家・星空小樹屋

以 Phaser 3 和 Vite 製作的療癒放置型寵物小遊戲。

## 開始遊玩

```sh
pnpm install
pnpm dev
```

## 遊戲內容

- 點擊狗狗、小貓或小兔，或使用右側按鈕與牠們互動。
- 星塵每分鐘自動增加；小點心會隨時間補充。
- 免費拜訪新地點，收集旅行郵票與星球明信片。
- 用星塵替小樹屋添購小燈、花盆與望遠鏡。
- 寫信給未來的自己，或翻閱收到的明信片。

遊戲進度保存在目前瀏覽器的 `localStorage`，沒有登入或伺服器需求。
